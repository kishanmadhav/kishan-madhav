# Kishan Madhav AG — Portfolio

Static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Included
- Responsive editorial portfolio layout
- Scroll reveals, cursor spotlight, project-card tilt, and progress indicator
- Custom animated SVG identity icons for Orbit, Nexus, and the federated learning project
- Reduced-motion accessibility support

## Assets
Place your résumé at `assets/Kishan-Madhav-Resume.pdf` to enable the CV download link.
